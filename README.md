# 跑团终端 · LAN Tabletop Chat

局域网即时聊天 + 战术地图 + 投屏 + 可插拔规则包。零外部运行时依赖，Node 单文件即可跑，也可打包成双击即开的 exe。

**核心只有三件事：聊天室、地图、投屏**（外加身份/GM 权限与插件宿主）；规则与扩展界面都是插件，丢目录即装。

- 实时消息（SSE 长连接，无需 WebSocket 库）
- 通用骰子：`!roll` / `!dN` / `!check`，支持优势劣势
- 规则包插件化：母舰、D&D 5e、CoC 7版、通用骰子都是 `plugins/rules/` 下的声明式插件，切换频道即切换规则（配色、品牌、快捷骰、指令手册、角色卡字段、专属指令随之变化）
- 扩展插件：`plugins/<名字>/plugin.json` 可加顶栏按钮、面板、内嵌网页面板、聊天命令宏、右栏区块。**纯数据、界面由宿主渲染**，装上陌生插件也不执行任何代码
- 母舰规则包内含完整 d20 恐慌表 + 四职业创伤反应（由插件数据声明，核心不含任何具体规则）
- 多频道 + GM 权限（可见全部、建/改/删频道、静音、代投）
- 角色卡（按频道隔离，含装备与卡面图）
- 战术地图：多楼层对象模型（矩形/直角多边形房间 + 无需命名的通道走廊 + 门/梯）。移动可达 = 真实几何相邻（房间/通道贴边或轻切 1 格内即相通），锁着的门挡住去路，跨层用“梯”门。玩家按所在楼层看布局，`!go` 沿可达网移动，GM 编辑/显示双模式与一键公开。**一个频道可同时放多张地图、样式自选**（舱室 / 方格战斗 / 场景线索板），GM 管清单与默认图，所有人可切换查看；地图与规则包解耦（规则只在首次开图时给默认样式）。地图数据是 **v6 多图结构**（`{v,maps:[{id,name,engine,data}],active,archived}`），旧版数据启动时自动升级
- 投屏网页：GM 把网页地址或本地图片推到当前频道，全员各自在**独立浮窗**里同看（可拖动/缩放/最小化，不占聊天区）
- 一键导出频道日志（.txt）

## 快速开始

### 方式一：双击启动（Windows，推荐）

双击 `start.bat`。脚本会优先使用同目录自带的 `node.exe`，无需本机安装 Node。

### 方式二：命令行

```bash
node server.js
```

### 方式三：单文件 exe

把 `build/mothership.exe` 拷到任意空文件夹双击运行。数据目录 `data/` 会自动生成在 **exe 同级目录**。

启动后终端会输出：

```
=== 母舰通讯终端已上线 ===
本机访问 : http://localhost:8080
局域网访问: http://192.168.x.x:8080
```

同网段设备（手机 / 笔记本 / 平板）浏览器打开「局域网访问」地址即可加入。

## 配置

| 项 | 默认值 | 改法 |
|---|---|---|
| 端口 | `8080` | 环境变量 `PORT`，例：`set PORT=3000 && node server.js` |
| 监听地址 | `0.0.0.0` | 固定，允许局域网访问 |

### GM 角色

GM 不是口令，而是一个**被某用户持有、可转让的角色**：

- 登录时在「角色」里选 **GM** 即认领；若此时 GM 已被别人持有，你会被自动降级为「玩家」
- GM 可在「设置 → GM 管理」里把 GM 转让给他人，或主动释放；释放后任何人可重新认领
- 没有 GM 选用主题时，全局默认 `generic`（通用）主题

### 规则包（插件）

规则由**频道**决定（设置里显示当前频道用哪套，GM 在「管理频道」改），该频道所有人都跟着变。插件放在 `plugins/rules/<名字>/rulepack.json`：

| 插件 | 地图模式 | 快捷骰 | 专属指令 |
|---|---|---|---|
| 母舰 Mothership 1e（标了 `default`，默认规则） | zone（舱室/区域） | d100、d20、检定、Panic、Stress | `!stress`、`!panic` |
| D&D 5e | square（方格） | d20、d4、d6、d8、d12 | — |
| CoC 7版 | scene（场景） | d100、检定、d10、d6、d3 | — |
| 通用骰子 | none | d20、d100、d6、2d6、d10 | — |

- 规则包是**纯 JSON 数据**：不能带 HTML / JavaScript / 远程地址 / 任意 CSS，装上陌生规则包也不会执行任何代码。
- 一个规则包能声明：品牌与配色、快捷骰按钮、地图模式（**只能选用**已有引擎）、角色卡字段分组、专属指令。字段说明见 `plugins/rules/README.md`。
- 优先级：GM 用「导入规则包」上传的（存 `data/rulesets/`）**覆盖**同名插件；插件目录整个删掉程序照跑（回退到内置的最小「基础（无规则）」包）。
- 角色卡字段完全由规则包声明驱动：换规则后同一张卡按新规则的字段重新渲染，旧格式（扁平字段）的卡片会在启动时自动迁移为通用 `values`。
- 所有规则共用通用指令 `!dN` 与 `!roll NdN+K`。
- 每套规则包可自带 `theme.css`（`plugins/rules/<名字>/theme.css`）：切到该规则时前端按当前频道规则自动链入这张样式表，整页 UI（右键菜单 / 按钮 / 地图区底色 / 头像底色 / 提及高亮等）跟随主题走。各主题通过覆盖 `style.css` 里的 CSS 变量实现，互不影响。通用（无规则）包不单独做主题，沿用 `style.css` 内联的兜底配色。

### 扩展插件（声明式）

除规则包外，`plugins/<名字>/plugin.json` 还能给程序加**界面与命令**，同样是纯数据、丢目录即装：

| 扩展点 | 能做什么 |
|---|---|
| `tools` | 顶栏加按钮（打开面板 / 直接发一条指令） |
| `panels` | 弹窗面板，内容用一套**封闭组件**描述：标题 / 文本 / 列表 / 表格 / 图片 / 键值 / 表单 / 按钮 / 分隔线 / 内嵌网页 |
| `webviews` | 内嵌网页面板（被站点拒绝嵌入时表现为空白，有「新窗口打开」兜底） |
| `commands` | 聊天命令宏：`expand` = 展开成指令（`!init` → `!roll 1d20`）；`list` = 从候选里随机挑一条 |
| `sideSections` | 右栏加区块 |
| `theme.accent` | 只给插件自己的按钮一个强调色（不覆盖频道规则的主题） |

**为什么装陌生人给的插件也安全**：清单里只有数据，界面**全部由宿主渲染**（只认上面那套封闭组件，一律 `createElement` + `textContent`，从不拼 HTML）；面板标题恒为「插件：<名>」，组件里没有密码框；静态资源只发图片 / CSS / 字体，**不发 `.js` / `.html`**。含代码的「可信插件」本期**只登记不启用**。

`plugins/ref-sheet/` 是一个把上面全部扩展点都用了一遍的官方示范（规则速查卡）。完整字段说明见 `plugins/README.md`。

- 启停 / 导入：GM 在「设置 → 插件」里操作（启停写 `data/plugins.json`，导入落 `data/plugins/<id>.json`）。**停用会立即对所有在线的人生效**（顶栏按钮、右栏区块一起消失，已经打开的插件面板自动收起），不用刷新页面；非 GM 只能看到清单，看不到启停 / 导入按钮。
- 卸载：删掉 `plugins/<id>/` 目录即可；改动后刷新页面生效。

## 玩家用法

1. 打开地址 → 输入**呼号**（≤20 字符）→ 选「角色」（GM / 玩家 / 观察者）→ 点「接入频道」
2. 选「玩家」为普通船员；选「观察者」可看频道但不可发言
3. 左侧切换频道，底部输入框发消息或投骰
4. 消息中 `@呼号` 会高亮并弹提示

### 骰子指令

输入框以 `!` 开头即为指令，也可用底部快捷按钮。

| 指令 | 说明 | 示例 |
|---|---|---|
| `!roll <表达式>` | 骰池，支持 `ndn` 与 `+/-` 常数 | `!roll 2d10+5` |
| `!r <表达式>` | 同上简写 | `!r 3d6-1` |
| `!d<n>` | 单骰 | `!d100`、`!d20` |
| `!check <目标值>` | d100 ≤ 目标值判定成败 | `!check 55` |
| `!panic` | Panic Check：d20 < Stress 则触发恐慌表（**母舰规则包提供**） | `!panic` |
| `!stress` | 查询当前 Stress（默认 2）（**母舰规则包提供**） | `!stress` |
| `!stress <n>` | 设置 Stress（0–99）（**母舰规则包提供**） | `!stress 6` |
| `!go <房间名>` | 沿"相邻(贴边/轻切)+未锁门/梯"移动到目标房间（进入未揭示房间会自动揭示） | `!go 医疗舱` |
| `!here` | 查看当前所在房间与可去之处 | `!here` |
| `!help` | 指令速查（含当前规则包的扩展指令） | `!help` |

**优势 / 劣势**：底部下拉框选「优势 Adv / 劣势 Dis」，或指令末尾手动加 `adv` / `dis`。

| 场景 | 优/劣势处理 |
|---|---|
| `!roll` / `!dN` | 投两组，优势取高、劣势取低，并展示另一组 |
| `!check` | 投两次 d100，优势取**低**、劣势取**高** |
| `!panic` | 投两次 d20，优势取**低** |

**注意**：`!stress` 由服务端按「规则包 + 呼号」记忆并存进 `data/counters.json`（重启不清空）；角色卡里的 Stress 字段是另一套，仅作记录。

### Panic Check 规则（由母舰规则包声明）

> 这张表写在 `plugins/rules/mothership/rulepack.json` 的 `commands` 里；核心只负责「掷骰 → 按阈值查表 → 附特性文本」这套通用逻辑。

- `d20 = 1` → FOCUS（获得优势）
- `d20 < 当前 Stress` → 触发恐慌表对应条目
- 否则 → 保持冷静，Stress -1（表内文字提示，需自行调整 `!stress`）
- 触发恐慌时，若当前频道角色卡填了职业，会附带对应创伤反应提示

职业匹配（中英文均可）：Scientist / 科学家、Teamster / 机械师 / 驾驶员、Android / 仿生人 / 机器人、Marine / 海军陆战队。

### 战术地图（玩家）

点顶栏「地图」打开。地图是**多楼层房间对象模型**——GM 在每一层画出矩形/直角多边形房间与通道走廊（相贴/轻切即互通），可加门（锁障）/梯（跨层）；房间可被 GM 隐藏（房间级迷雾）。

- 玩家**只能看到自己所在楼层**的已公开内容；其他楼层的布局完全看不到（服务端不返回）
- 打开地图看布局：所在楼层的房间、其他玩家位置、通道走向
- **移动在聊天框用 `!go 房间名`**（沿相邻/轻切 + 未锁门/梯的可达网移动；走梯子可跨到别的楼层）
- `!here` 看当前位置与可去的房间列表
- 进入未被 GM 揭示的房间会自动揭示（对所有玩家）
- 视图：滚轮缩放、拖拽平移、点「适应」回全图

### 角色卡

点右上角「角色卡」：

- 字段表由**当前频道的规则包**决定：母舰是职业 + 八维 + Stress/Wounds，D&D 5e 是职业/等级/六属性/战斗值，CoC 7 是调查员+九属性+派生值，通用只有概念与自由文本
- 均可填备注、装备（每行一项）、卡面图
- 母舰规则包下，职业字段会被 `!panic` 读取用于创伤反应
- 数据只存通用 `values` 表（键=规则包声明的字段名）；旧版扁平字段的卡在服务启动时自动迁移
- 卡片**按频道隔离**：不同频道可存不同的卡；`房间::呼号` 为唯一键
- 只能删除自己的卡；点击别人的卡可查看并载入到表单（再保存会存成你自己的）

## GM 用法

登录时在「角色」选 **GM** 即认领 GM（若已有人持有，会自动降级为玩家）。GM 可在「设置 → GM 管理」转让给他人或释放。GM 选定后，全局主题跟随其选择的规则包。

| 能力 | 说明 |
|---|---|
| 全频道视图 | 左侧顶部「全部频道」，同时看到所有频道消息流 |
| 频道管理 | 左下角「⚙ 管理频道」：新建、改名、设置白名单、静音、删除 |
| 战术地图 | 每频道一张，绘制矩形/直角多边形房间与通道，用门/梯子连起来，指定入口与已揭示房间（见下节） |
| 白名单 | 「开放给」留空=所有人；填 `艾达,鲍勃` 则仅这两人可见 |
| 静音 | 频道行点「静音」→ 输入呼号，切换静音状态（被静音者仍能看，不能发） |
| 踢出 | 从白名单移除某人 → 该人立即被断开并踢回主频道 |
| 删除频道 | 该频道消息一并清除，成员被踢回主频道（主频道不可删） |
| 代投 | 指令末尾加 `@呼号`，结果归属到该呼号，消息标「代投」 |
| 投屏 | 顶栏「投屏」：推网页地址或上传图片到当前频道，全员在独立浮窗里同看；只有 GM 能推 / 清除 |
| 导出 | 在「全部频道」视图点「导出」可得全频道日志 |
| 画地图 | 地形、迷雾、梯子、房间名由 GM 独占绘制（见下节） |

代投示例：

```
!check 55 @艾达        → 艾达的 55 检定
!panic @鲍勃          → 读取鲍勃角色卡职业，触发他的创伤反应
!roll 2d10+5 @艾达    → 艾达的伤害骰
```

非 GM 使用 `@` 会提示「只有 GM 可代投他人骰子」。

### 记录控制（GM）

默认**不记录**——只有 GM 显式开始后才把跑团内容写入导出日志，避免杂聊入档。被记录的是 dice / 发言 / 场景，不含接入提示与 `!log` 控制消息。

| 指令 | 作用 |
|---|---|
| `!log start` | 开始一段记录（之后本频道内容入档） |
| `!log end` | 结束整段记录 |
| `!log off` | 中途暂停（当前内容不再入档） |
| `!log on` | 从中途继续（恢复记录） |
| `!log status` | 查看当前状态（未开始 / 记录中 / 已暂停） |

> 只有 GM 能控制。`!log start` 到 `!log end` 之间、且未被 `!log off` 暂停的部分才会被「导出」下载成 .txt；其余聊天不入档。

> 应用内使用指引：GM 登录后，导出按钮左侧的「记录」状态徽标**可点击**，点开即显示 `!log` 指令清单，点任意命令可直接发送。

### 地图引擎：一个频道可以同时放**多张地图**，样式随你挑

地图和规则包**解耦**了：规则包只管角色卡 / 配色 / 骰子；地图由 GM 在地图弹层左上「地图」清单里自己增删、改名、选样式、设默认。**上手**：打开地图 → 左上「＋新地图」→ 填名字、选样式（舱室 / 方格 / 线索板）→ 下拉随时切换。所有人默认看 GM 设的「默认图」，也能自己切去看别的（本机的选择只影响自己）；不会操作就点地图右上角的 **`?`**——说明按当前引擎显示对应玩法。单频道上限 12 张。

| 引擎 | 谁用 | 长什么样 | 能做什么 |
|---|---|---|---|
| `zone` | 母舰 Mothership 1e | 舱室 / 区域（多楼层） | 房间 / 通道 / 门梯 / 迷雾与楼层（见下一节）；`!go` / `!here` 用频道里的 zone 图 |
| `square` | 龙与地下城 D&D 5e | 方格战斗地图 | 棋子（PC/敌人/物件，1×1～3×3）、拖动、测距（5 ft/格，对角按 D&D 交替 5/10）、文字标记、墙、背景图；右键棋子＝改属性 / 复制 / 隐藏 / 删除；玩家默认能拖**自己的**棋子（按归属呼号，GM 可在「网格…」关掉） |
| `scene` | 克苏鲁的呼唤 CoC 7 | 线索板 | 卡片（地点/人物/线索/物品/事件）+ 带箭头的连线，可逐张**揭晓**给玩家 |
| `none` | — | （清空频道地图） | 删光频道里所有图后不再自动建图；再「＋新地图」即恢复 |

每个引擎的数据独立存放、互不干扰；新建频道第一次打开地图时，按规则包的 `map.mode` 自动建一张默认图，之后与规则无关。旧 v5 数据（按规则换引擎的版本）启动时自动升级为多图结构，原数据不丢。

**方格战斗地图（GM，D&D 5e 等）**

| 操作 | 方法 |
|---|---|
| 放棋子 | 侧栏「＋PC / ＋敌人 / ＋物件」→ 点格子 → 页内小框填名称、占格（1×1 / 2×2 / 3×3）、颜色、归属呼号、是否对玩家隐藏 |
| 移动棋子 | 「选择」→ 拖动，落点自动吸附格子；双击棋子改全部属性（表单里可删除） |
| 测距 | 「测距」→ 按住拖出，松开显示「N 格 · N×5 ft」；中间有墙会标「受阻」 |
| 标记 / 墙 | 「标记」点格子写文字；「画墙」拖一条直线（测距穿过会提示） |
| 网格与背景 | 「网格…」设置列 / 行、每格英尺、背景图 URL 与不透明度；「允许玩家移动自己的棋子」默认开，可关 |
| 擦除 | 「擦除」点掉棋子 / 墙 / 标记 |

**线索板（GM，CoC 7 等）**

| 操作 | 方法 |
|---|---|
| 放卡片 | 侧栏「＋地点 / ＋人物 / ＋线索 / ＋物品 / ＋事件」→ 点空白处 → 填标题、类型、正文、图片 URL、是否**揭晓** |
| 连线 | 「连线」→ 点第一张卡、再点第二张卡（带箭头）；双击线可加标签 / 隐藏 / 删除 |
| 修改 / 删除 | 「选择」→ 拖动摆放；双击卡片改内容（表单里有删除） |
| 批量 | 「揭晓全部 / 隐藏全部」一键对玩家公开或收回 |
| 擦除 | 「擦除」点掉卡片或连线（删卡片会连带清掉它的连线） |

> 隐藏棋子与未揭晓卡片**由服务端过滤**——玩家根本收不到这些数据（不是靠前端不画）。编辑操作仅 GM 可用；玩家默认能拖动**归属呼号等于自己**的棋子（GM 可在「网格…」关掉），服务端会再核对一次归属。

### zone 引擎：房间 / 通道地图（GM）

每频道一张**多楼层**地图。基础元素：**房间**（矩形 / 直角多边形，可命名）、**通道**（细长走廊，连通媒介）、**门 / 梯**（可选锁障 / 跨层通道）。连通规则：**同层任意两对象真实距离 ≤1 格（贴边或轻切）即相通**，无需显式连线；门只作"锁"，梯用于跨层。

打开地图默认是**编辑模式**（带网格与坐标辅助）。顶栏可切「编辑 / 显示」；**显示模式**隐藏网格和全部绘制工具，等同玩家视角（干净展示）。

**编辑模式操作：**

| 操作 | 方法 |
|---|---|
| 新建楼层 | 画布上方「＋楼层」，可起名；每层各自独立绘制 |
| 切换/删楼层 | 点楼层 tab 切换；tab 上的 ✕ 删除该层（会连带删掉该层房间与连接，至少留一层） |
| 画矩形/多边形房间 | 选「矩形 / 多边形」→ 拖拽（多边形逐点点击，点回首点闭合）→ 松开后弹出**确认+命名**对话框 →「确认创建」 |
| 画通道 | 选「通道」→ 拖拽出细长矩形，**松开即建、无需命名**。伸到任何对象旁即可互通 |
| 拖拽预览 | 拖拽中实时显示尺寸与状态色：**绿=已连通**（贴边/轻切 1 格内）、黄=需再拉近、红=穿入过深无法确认。房间之间只禁过度重叠，通道可轻微切入（≤1 格）以连上矩形/多边形 |
| 连通方式 | **几何相邻即相通**：矩形房间之间可贴边；直角多边形房间用「通道」伸到其任一边旁 1 格内（或轻切 ≤1 格）即可连通，创建时会自动吸附提示 |
| 房间间建门 | 选「门/梯」→ 依次点两个**相邻**对象放门（可点选后锁/开锁）；两个对象不在同一层会自动改成「梯」 |
| 设为入口 | 用「选择」点中房间 → 点「设为入口」。新玩家首次进入此频道默认出生在入口房间 |
| 揭晓/隐藏 | 选中房间 → 点「揭晓/隐藏」。隐藏的房间对玩家完全不可见（服务端不返回数据） |
| **一键公开** | 顶栏「公开本层」把所有房间对玩家揭示；「公开全部」揭开全部楼层 |
| 删除选中 | 选中对象后点「删除」 |
| 撤销/重做 | `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`，或工具栏按钮 |
| 导出 | 点「PNG」导出当前楼层为图片 |
| 视图 | 滚轮缩放、拖拽平移、点「适应」回全图 |

图例（绿色系，底层暗、上层亮）：房间=亮绿边框暗绿填充、通道=稍亮矩形、门=亮绿实线、梯子=亮黄虚线、玩家=彩色圆点（呼号稳定配色+首字）、入口房标★入口。跨层梯子在本层一端标注 ↘目标层。未揭示房间在 GM 视图呈暗色提示。

> 地图改动只广播「版本号」，玩家端收到后重新拉取；**玩家只看自己所在楼层**，且该层未揭示房间不返回，因此别层布局与隐藏房间都不会泄露。
> 玩家用 `!go 房间名` 沿"几何相邻（贴边/轻切）+ 未锁门/梯"的可达网移动：同层相邻即能走（通道是中间媒介，可贯穿）；锁着的门断开路径；走「梯」可跨到别的楼层（所在层随所在房间自动变化）。进入未揭示房间会同时揭示给所有玩家。

## 投屏网页（共享舞台）

GM 在顶栏点「投屏」，二选一：

| 方式 | 说明 |
|---|---|
| 推网页地址 | 填 `http(s)://…` 完整地址，服务端只收 http/https |
| 上传图片 | png / jpg / gif / webp，**≤ 3MB**（落盘到 `uploads/`） |

- 推送后**本频道所有人**各自弹出一个**独立浮窗**播放同一份内容，**不占用聊天区**——聊天气泡不被挤压，可以一边看投屏一边打字。
- 浮窗可**拖动**（拖标题栏）、**缩放**（右下角把手）、**最小化**（标题栏 `—`）。位置与大小记在本机，刷新后照旧。
- 最小化后只在右下角留一枚「◧ 投屏中」浮动药丸，点它唤回窗口。最小化是**只影响自己**的状态，刷新后仍然保持（服务端按人记名）。
- 权限：推 / 清除 = **GM 专用**；最小化 = 人人可用。非 GM 看不到顶栏「投屏」按钮（手机版在「更多」菜单里）。
- 局限：部分站点用 `X-Frame-Options` / CSP 拒绝被嵌入，浮窗会显示空白——点右上角「↗」在新窗口打开即可（被拒时浮窗右下角会弹一次提示）。局域网是 http 环境，浏览器禁止 `getDisplayMedia`，所以**不支持真正的屏幕镜像**（只能推网页 / 图片）。

> 投屏状态按频道存 `stage.json`，变更只广播版本号（与地图同款模式），各端自行重拉。窗口的位置/尺寸只存浏览器 `localStorage`，与账号无关。

## 数据文件

运行时自动生成于 `data/`（`node server.js` 时在项目根；exe 时在 exe 同级）：

| 文件 | 内容 |
|---|---|
| `rooms.json` | 频道列表、白名单、静音名单 |
| `messages.json` | 消息记录，**每频道仅保留最近 500 条** |
| `characters.json` | 角色卡（含 base64 卡面图） |
| `map.json` | 战术地图（每频道一份 **v5 多引擎结构** `{v,engine,blocks,archived}`：`blocks.zone` 存多楼层 floors、房间/通道/门梯子、入口；换规则不删旧块，只记 `archived`。玩家位置存内存，重启清零） |
| `logs.json` | 记录控制（`!log`）导出的跑团记录 |
| `stage.json` | 投屏状态（每频道：类型 / 地址 / 推送人 / 收起名单） |
| `counters.json` | 规则扩展指令的计数器（如母舰 Stress）：键 = 规则包 + 玩家 |
| `rulesets/*.json` | GM 导入的规则包（优先级高于内置插件） |
| `plugins.json` | 扩展插件的启停状态 `{disabled:[...]}` |
| `plugins/*.json` | GM 在界面上导入的声明式扩展插件 |

上传的投屏图片另存于 `uploads/`（与 `data/` 同级，exe 时在 exe 旁边）。

备份 / 迁移：整个 `data/` 与 `uploads/` 一起拷走即可。

## HTTP API

前端即通过这些接口通信，可自行扩展：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/events?room=&user=&gm=` | SSE 订阅；GM 传 `room=*` 收全部 |
| POST | `/api/send` | 发消息 / 指令 / `type:join` |
| GET | `/api/rooms?user=&gm=` | 频道列表 |
| POST | `/api/rooms` | 建频道（GM） |
| PUT | `/api/rooms/:id` | 改频道（GM）：`name` / `allowed` / `ruleset`。换规则**不影响**频道里的地图（地图已与规则解耦） |
| DELETE | `/api/rooms/:id` | 删频道（GM） |
| POST | `/api/mute` | 静音开关（GM） |
| GET | `/api/characters?room=&gm=` | 读角色卡；`room=*` 需 GM |
| POST / DELETE | `/api/characters` | 存 / 删角色卡（字段按频道规则包校验，只存 `values`） |
| GET | `/api/rulesets` | 列出已装载的规则包（插件目录 + GM 导入） |
| POST | `/api/rulesets/import` | 导入声明式规则包 JSON（GM），同 id 覆盖插件 |
| GET | `/api/plugins` | 列出全部扩展插件（含未启用者与原因）；启用者附 `contributes`（扩展点声明），**不含任何可执行代码** |
| POST | `/api/plugins/import` | 导入单个声明式插件 JSON（GM），落 `data/plugins/<id>.json`；含代码的可信插件会被拒收 |
| POST | `/api/plugins/toggle` | 启用 / 停用插件（GM），写 `data/plugins.json` |
| GET | `/plugins/<id>/<文件>` | 插件静态资源（仅图片 / CSS / 字体 / JSON，**不发 `.js`、`.html`**；有路径穿越防护） |
| GET | `/api/roomlog?room=&user=&gm=` | 导出频道日志；`room=*` 需 GM |
| GET | `/api/map?room=&user=&gm=&mid=` | 读地图（`mid` 可选，缺省＝频道默认图）。返回 `{v, maps:[{id,name,engine}], active, mapId, map}`。非 GM 服务端按迷雾 / hidden / revealed 过滤，`room=*` 需 GM |
| POST | `/api/map/op` | 地图增量操作（`ops` 数组，每条可带 `mid` 指定哪张图，缺省＝默认图）。频道级（仅 GM）：`map.create` / `map.del` / `map.rename` / `map.active`。图内数据 op 由**那张图的引擎**处理，引擎前缀只是兼容写法：zone 的 `room.upsert` / `room.del` / `passage.upsert` / `passage.del` / `door.set` / `door.del` / `door.lock` / `entry` / `explore(.floor/.all)` / `floor.add` / `floor.del` / `types.set` / `radar.set` / `entry.toggle`；square 的 `grid.set` / `token.upsert|move|del` / `wall.upsert|del` / `mark.upsert|del` / `clear`；scene 的 `node.upsert|del` / `link.upsert|del` / `clear`。仅 GM 可写；**唯一例外**是 square 图上的 `token.move`（默认放行：只能动归属呼号为自己的棋子，GM 可在「网格…」关闭） |
| POST | `/api/map` | 整体替换某张图（GM）：`{engine, block, mid?, name?}`——带 `mid` 覆盖那一张，不带则覆盖当前默认图（频道一张图都没有时自动新建）。导入内容过服务端清洗（限长 / 白名单色 / 数量上限） |
| GET | `/api/stage?room=&user=&gm=` | 读本频道投屏状态（含本端是否已收起） |
| POST | `/api/stage/op` | 投屏操作：`stage.push`（推网页）/ `stage.clear`（清除）= GM；`stage.hide`（收起/展开，写入自己的 `hiddenFor`）= 人人可用 |
| POST | `/api/stage/upload` | 上传图片并投屏（data URL，png/jpg/gif/webp，≤ 4MB 落盘、前端先限 3MB），仅 GM |
| GET | `/uploads/<file>` | 投屏上传图片的静态分发（禁路径穿越） |

## 常见问题

**局域网其他设备打不开** — Windows 防火墙放行 Node（或 exe）的入站：
```powershell
netsh advfirewall firewall add rule name="Mothership Chat" dir=in action=allow protocol=TCP localport=8080
```
另确认设备在同一网段、地址用的是「局域网访问」那行而非 localhost。

**端口被占用** — 换端口：`set PORT=8081 && node server.js`

**提示「离线 / 重连中」** — SSE 每 25 秒心跳保活；断线会自动重连，无需刷新。被 GM 移出频道时会收到系统提示并自动跳回主频道。

**消息丢失** — 每频道只存最近 500 条，超出的旧消息会被丢弃，重要内容及时「导出」。

**Stress 归零了** — `!stress` 存在内存，服务重启后回到默认 2。
