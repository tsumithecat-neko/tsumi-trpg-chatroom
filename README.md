# tsumichat · LAN Tabletop Chat

**一台电脑开房间，同一个 WiFi 下的所有人用浏览器连进来跑团。**

双击一个 exe 就能用，**不用装 Node、不用联网、不用注册**。聊天、投骰、地图、投屏、背景音乐都在同一个页面里。

---

## 一、开房间（GM 做，只做一次）

### 1. 把 exe 放到一个空文件夹里

拿到 `tsumichat.exe`（约 37 MB，Windows 64 位），把它放进一个空文件夹，比如 `D:\跑团\`。

程序会在**同一个文件夹**里自动生成 `data\` 目录，所有东西都存那里 —— 消息、地图、角色卡、上传的图片和音频。

> **想换电脑或备份整个团？** 直接把整个文件夹拷走就行，`data\` 跟着走，不用导出导入。

### 2. 双击运行

会弹出一个黑色命令行窗口，显示：

```
=== tsumichat 已上线 ===
本机访问 : http://localhost:8080
局域网访问: http://192.168.1.23:8080
在同网段设备上用上面的局域网地址打开即可。
```

- **这个黑窗口就是房间本体，关掉它房间就散了**。跑团期间让它开着（可以最小化）。
- Windows 第一次运行可能弹「是否允许访问网络」，选**允许**（专用网络）。不给权限的话别人连不上。
- 如果系统提示端口被占用，见文末「常见问题」。

### 3. 把地址发给大家

- 你自己：浏览器打开 `http://localhost:8080`
- 其他人：打开那行**「局域网访问」**的地址（形如 `http://192.168.1.23:8080`）

所有人必须在**同一个局域网**里（同一个 WiFi / 同一个路由器）。手机、平板、笔记本都行，用浏览器打开就能进，**不需要装任何东西**。

## 二、进房间

<p align="center">
  <img src="docs/screenshots/01-login.png" width="440" alt="登录界面：输入呼号、选择身份" />
</p>

<p align="center"><sub>登录界面 —— 输入呼号、选身份，点「接入频道」</sub></p>

1. 浏览器打开地址 → 输入**呼号**（最多 20 个字）→ 选身份 → 点「接入频道」
2. 三种身份：

| 身份 | 能做什么 |
|---|---|
| **GM / 主持人** | 管频道、画地图、投屏、放音乐、选规则。同时只能有一个人担任 |
| **玩家** | 发言、投骰、看地图、填自己的角色卡 |
| **观察者** | 只看不说话（围观 / 记笔记用） |

3. 手机 / 平板打开同一个地址会自动进**手机版**：底部三个标签「通讯 / 雷达 / 角色」，雷达页能直接点着走。桌面版可以在「设置 → 界面模式」里切换。

**GM 是「可转让的角色」，不是密码：**

- 登录时选 GM 就认领了；如果此刻已经有人是 GM，你会被自动降级为玩家
- GM 可以在「设置 → GM 管理」里把 GM 转让给别人的呼号，或者主动释放让其他人认领

## 三、怎么投骰

输入框里以 `!` 开头就是指令，也可以用底部的快捷按钮。

| 指令 | 说明 | 示例 |
|---|---|---|
| `!roll <表达式>` | 骰池，支持 `ndn` 与 `+/-` 常数 | `!roll 2d10+5` |
| `!r <表达式>` | 同上简写 | `!r 3d6-1` |
| `!d<n>` | 单骰 | `!d100`、`!d20` |
| `!check <目标值>` | d100 ≤ 目标值判定成败 | `!check 55` |
| `!panic` | Panic Check：d20 < Stress 触发恐慌表（**母舰规则**） | `!panic` |
| `!stress` | 查询当前 Stress（默认 2）（**母舰规则**） | `!stress` |
| `!stress <n>` | 设置 Stress（0–99）（**母舰规则**） | `!stress 6` |
| `!go <房间名>` | 在地图上移动到目标房间 | `!go 医疗舱` |
| `!here` | 看自己在哪、能去哪 | `!here` |
| `!help` | 指令速查（含当前规则的扩展指令） | `!help` |

**优势 / 劣势**：发送栏的下拉框选「优势 Adv / 劣势 Dis」，或在指令末尾加 `adv` / `dis`。`!roll` 投两组取高/低，`!check` 投两次 d100（优势取低），`!panic` 投两次 d20（优势取低）。

**GM 代投**：指令末尾加 `@呼号`，结果算在那个人的头上，消息会标「代投」。

```
!check 55 @艾达        → 艾达的 55 检定
!panic @鲍勃          → 读鲍勃的角色卡职业，触发他的创伤反应
!roll 2d10+5 @艾达    → 艾达的伤害骰
```

> 母舰规则下的职业匹配（中英文都认）：Scientist / 科学家、Teamster / 机械师 / 驾驶员、Android / 仿生人 / 机器人、Marine / 海军陆战队。

## 四、地图

点顶栏的**「地图」**打开。地图有四种样式，GM 在建图时挑：**区域**（房间 / 走廊 / 门 / 梯子）、**方格**（战斗图）、**线索**（场景板）、**不放地图**。一个频道可以同时放多张。

**玩家能做的：**

- 看到**自己所在楼层**的已公开部分（其他楼层服务端根本不发给你）
- 用 `!go 房间名` 移动，走门 / 梯子跨层；进入没揭示过的房间会自动揭示给所有人
- `!here` 看当前位置和可去的地方
- 滚轮缩放、拖拽平移、点「适应」回到全图

**GM 能做的：**

- 画房间 / 走廊（贴边或轻切 1 格内就算相通）、加门（可上锁）、加梯子（跨楼层）
- 一层一层画，切换楼层；房间可以整间隐藏（玩家那边就是黑的），需要时再公开
- 管理地图清单：加图、改名、换样式、删图；旧的图会归档保留，随时切回来
- 地图是**跟着频道**的，换规则不会删你的图

## 五、GM 的能力清单

点顶栏的 `⋯` 菜单，里面是常用入口。

| 能力 | 在哪 | 说明 |
|---|---|---|
| 频道管理 | 左下角「⚙ 管理频道」 | 新建、改名、设白名单、静音、删除 |
| 规则主题 | `⋯` → 设置 → 规则主题 | 切换本频道的规则：皮肤、骰子、快捷骰、角色卡字段、专属指令一起换 |
| 地图 | 顶栏「地图」 | 见上一节 |
| 投屏 | `⋯` → 投屏到本频道 | 推网页地址或上传图片，全员在独立浮窗里同看；可拖动 / 缩放 / 最小化 |
| 频道音响 | `⋯` → 频道音响 | 放背景音乐和音效，全员同步听 |
| 全服皮肤 | `⋯` → 插件 → 主题工坊 | 调一次色，全服所有人（含手机版）实时跟着变 |
| 记录与导出 | 全部频道视图 → 导出 | 见下方「记录控制」 |
| 白名单 | 频道管理 | 留空 = 所有人可进；填 `艾达,鲍勃` 则只有这两人看得到这个频道 |
| 静音 / 踢出 | 频道行 | 静音后能看不能说；从白名单移除即踢出并送回主频道 |

### 频道音响

`⋯` → **频道音响**：

1. 上传本地音频文件，或者粘一条直链（mp3 / ogg / m4a / wav 等）
2. 曲库里点 **▶** 就是背景音乐（默认循环）；点「**一次**」就是单次音效
3. 拉动进度条可以跳转，主音量全服统一

**所有人同步听** —— 中途进来、掉线重连的人会自动追上同一个位置。每个人可以**本地静音 / 调自己的音量**，不影响别人。左下角有浮动播放条，可以收成 ♪ 药丸，不挡界面。

### 记录控制（GM）

默认**不记录** —— 只有 GM 显式开始之后，跑团内容才会进导出档，日常闲聊不入档。

| 指令 | 作用 |
|---|---|
| `!log start` | 开始一段记录 |
| `!log end` | 结束整段记录 |
| `!log off` / `!log on` | 中途暂停 / 继续 |
| `!log status` | 查看当前状态 |

`!log start` 到 `!log end` 之间（且没被 `!log off` 暂停）的内容，才会被「导出」下载成 `.txt`。被记录的是骰子、发言和场景，不含接入提示和 `!log` 控制消息。

### 角色卡

`⋯` → 角色卡。字段跟着**当前频道的规则**走：母舰是职业 + 八维 + Stress/Wounds，D&D 5e 是职业/等级/六属性/战斗值，CoC 7 是调查员 + 九属性 + 派生值，通用只有概念和自由文本。都能填备注、装备、卡面图。

角色卡**按频道隔离**，不同频道可以存不同的卡；只能删自己的卡，点别人的卡可以查看。

## 六、常见问题

**别人打不开** —— 三件事按顺序查：

1. Windows 防火墙放行（管理员身份运行 PowerShell，一条命令）：
   ```powershell
   netsh advfirewall firewall add rule name="Tsumichat" dir=in action=allow protocol=TCP localport=8080
   ```
2. 确认大家和设备在**同一个网段**（同一个 WiFi / 同一个路由器）
3. 发的是**「局域网访问」**那行的地址，不是 `localhost`

**端口被占用** —— 换个端口：在命令行里先 `set PORT=8081`，再运行 exe，然后把地址里的 `8080` 换成 `8081`。

**黑窗口被我关了** —— 那就是把服务器关了，房间直接解散。重新双击 exe 即可，数据都还在。

**显示「离线 / 重连中」** —— 正常的，会自动重连，不用刷新。被 GM 移出频道时会收到提示并自动回主频道。

**消息丢了** —— 每个频道只保留最近 500 条，更早的会被丢掉。重要的内容记得用「导出」存档。

**Stress 归零了** —— 不会，Stress 存在 `data/counters.json` 里，重启也保留。

**杀毒软件报毒** —— 这种「打包成单文件」的 exe 有时会被误报。加进白名单即可。

**游戏中途换台电脑** —— 把整个文件夹（含 `data\`）拷到新电脑，双击 exe，一切照旧。
